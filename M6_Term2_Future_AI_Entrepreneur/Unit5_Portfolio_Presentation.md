### คาบที่ 34: จัดทำพอร์ตโฟลิโอ (1/2) — โครงสร้าง ภาพ วิดีโอ และบทบาทของตนเอง
- **จุดประสงค์การเรียนรู้:**
  1. คัดเลือกและจัดเตรียมหลักฐานผลงานตลอดหลักสูตร ม.4–ม.6 (ภาพถ่ายฮาร์ดแวร์/ซอฟต์แวร์, คลิปเดโม, กราฟผลทดสอบ) ได้
  2. เขียนบรรยาย **"บทบาทและความรับผิดชอบของตนเอง (Individual Contribution)"** ในงานกลุ่มให้ชัดเจนและน่าเชื่อถือได้
- **แนวคิดหลัก:** พอร์ตโฟลิโอที่ดีไม่ใช่แค่โชว์รูปสวย ๆ แต่ต้องบอกให้ได้ว่า *"ปัญหาคืออะไร → เราทำส่วนไหนด้วยตัวเอง → ผลลัพธ์วัดเป็นตัวเลขได้เท่าไร"*
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | แสดงตัวอย่าง Portfolio สาย AI/วิศวะ 2 แบบ (แบบเว็บ และแบบเอกสาร PDF) |
  | 5–15 นาที | บรรยาย/สาธิต | สอนโครงสร้าง Project Case Study ในพอร์ต (Context → My Role → Process/Tech → Measurable Result) |
  | **15–50 นาที (70%)** | **โครงงานปลายคาบ** | ลงมือรวบรวมหลักฐานและเขียนร่าง Portfolio รายบุคคล |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** คลังหลักฐานและโครงร่าง Portfolio รายบุคคล
  - **โจทย์/สถานการณ์:** ผู้เรียนแต่ละคนรวบรวมผลงานเด่นตลอด 3 ปี (ม.4 Mini Project → ม.5 AI Vision / AIoT → ม.6 Capstone) มาจัดทำโครงสร้างพอร์ตโฟลิโอส่วนตัว
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** เอกสารโครงร่างพอร์ตโฟลิโอรายบุคคล (LibreOffice Writer / Markdown [เสริม]/Slides) ที่มี ≥ 3 โครงงานเด่น พร้อมภาพประกอบ คลิป/ลิงก์ Local Git Server ผลทดสอบตัวเลข และคำอธิบายบทบาทของตนเองชัดเจน
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. เลือกแพลตฟอร์มที่จะทำพอร์ต (เว็บ เช่น Static HTML / Markdown Portfolio บน NAS [เสริม]/เอกสาร Markdown บน NAS [เสริม]/Local Git Server Pages หรือ เอกสาร PDF ด้วย โปรแกรมออกแบบออฟไลน์ (LibreOffice Impress / Draw.io) [เสริม])
    2. รวบรวมภาพ คลิป และตัวเลขผลทดสอบจาก ม.4, ม.5, ม.6
    3. เขียนคำอธิบายแต่ละโครงงานโดยเน้น **"My Role"** (ส่วนที่ตนเองลงมือทำจริง) และผลลัพธ์เชิงตัวเลข
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - รวบรวมผลงานครบ ≥ 3 ชิ้นพร้อมหลักฐานจริง (ภาพ/ลิงก์/ตัวเลข) (4 คะแนน)
    - ระบุบทบาทของตนเองในงานกลุ่มได้ชัดเจนไม่คลุมเครือ (4 คะแนน)
    - โครงสร้างเนื้อหาเรียงลำดับน่าสนใจ (2 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** หน้า Capstone ระบุชัด: "รับผิดชอบ: พัฒนาโมเดล MobileNetV2 และทำ Data-Centric Tuning จนความแม่นยำเพิ่มจาก 84% เป็น 93%" พร้อมภาพ Confusion Matrix
  - **ตัวเลือกเสริม (Extension):** สร้าง QR Code ลิงก์ไปคลิปสาธิตหรือ Local Git Server สำหรับใส่ในเวอร์ชัน PDF
  - **แนวทางช่วยเหลือ (Scaffold):** แจกโครงร่าง Project Card 4 ช่อง (ปัญหา / บทบาทฉัน / เครื่องมือที่ใช้ / ผลลัพธ์)
- **วัสดุ/เครื่องมือที่ต้องเตรียม:** คอมพิวเตอร์, คลังภาพ/วิดีโอผลงาน ม.4–ม.6, โปรแกรมออกแบบออฟไลน์ (LibreOffice Impress / Draw.io) [เสริม] / Static HTML / Markdown Portfolio บน NAS [เสริม] / เอกสาร Markdown บน NAS [เสริม]
- **คำถามสะท้อนคิดปิดคาบ:**
  1. ใน 3 ปีที่ผ่านมา โครงงานไหนที่แสดงให้เห็นทักษะเฉพาะตัวของคุณได้ชัดเจนที่สุด?

### คาบที่ 35: จัดทำพอร์ตโฟลิโอ (2/2) — ประกอบพอร์ตโฟลิโอแบบเว็บหรือเอกสาร
- **จุดประสงค์การเรียนรู้:**
  1. ออกแบบและจัดหน้าพอร์ตโฟลิโอ (แบบเว็บไซต์ หรือ PDF) ให้สวยงาม อ่านง่าย และมีลำดับการเล่าเรื่องที่ดีได้
  2. ตรวจสอบลิงก์ QR Code และความถูกต้องของเนื้อหาทั้งหมดก่อนนำไปใช้จริงได้
- **แนวคิดหลัก:** การจัดวางองค์ประกอบ (Visual Hierarchy) ที่ดีช่วยให้กรรมการเห็นจุดเด่นของผู้เรียนภายใน 30 วินาทีแรกที่เปิดดู
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | แนะนำหลักจัดวางพอร์ต (ปก–ประวัติ–ทักษะ–ผลงานเด่น–กิจกรรม/รางวัล) |
  | **5–50 นาที (90%)** | **โครงงานปลายคาบ** | ลงมือประกอบพอร์ตโฟลิโอฉบับสมบูรณ์ + ให้เพื่อนช่วยตรวจลิงก์ |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** พอร์ตโฟลิโอรายบุคคลฉบับสมบูรณ์ (Personal AI & Robotics Portfolio)
  - **โจทย์/สถานการณ์:** ประกอบเนื้อหาจากคาบ 34 ให้เป็นพอร์ตโฟลิโอที่สวยงามพร้อมส่งสมัครเรียนต่อหรือแนบสมัครงาน/ประกวด
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** พอร์ตโฟลิโอแบบเว็บ (Published URL) หรือเอกสาร PDF (≥ 6–10 หน้า) ฉบับสมบูรณ์ที่มี หน้าปก, Bio/Skills, ผลงาน ≥ 3 ชิ้น (เน้น Capstone), และลิงก์/QR Code ที่เปิดได้จริงทั้งหมด
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. นำโครงร่างและภาพจากคาบ 34 มาจัดวางลงเทมเพลตเว็บ/โปรแกรมออกแบบออฟไลน์ (LibreOffice Impress / Draw.io) [เสริม]
    2. ใส่หน้า Skills สรุปทักษะ (Python, MicroPython, ML/DL, OpenCV, IoT/MQTT, Agile)
    3. ตรวจคำผิด ทดสอบคลิกลิงก์/สแกน QR Code ทุกจุดในพอร์ต
    4. ส่งออก PDF หรือกด Publish เว็บส่งครู
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - จัดวางสวยงาม อ่านง่าย เป็นมืออาชีพ (4 คะแนน)
    - เนื้อหาครบถ้วน แสดงหลักฐานผลทดสอบและบทบาทตนเองชัดเจน (4 คะแนน)
    - ลิงก์/QR Code ทั้งหมดใช้งานได้จริง (2 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** เว็บไซต์/PDF 8 หน้า ดีไซน์คุมโทนสะอาดตา โชว์ผลงาน ม.4–ม.6 ครบ พร้อม QR Code ดูคลิปเดโมและ Local Git Server ที่สแกนติดทุกอัน
  - **ตัวเลือกเสริม (Extension):** ทำฉบับย่อ 1 หน้า (1-Page Resume/CV) แนบไว้หน้าแรกหรือไฟล์แยก
  - **แนวทางช่วยเหลือ (Scaffold):** แจกเทมเพลต Portfolio ใน โปรแกรมออกแบบออฟไลน์ (LibreOffice Impress / Draw.io) [เสริม] / Static HTML / Markdown Portfolio บน NAS [เสริม] ที่ออกแบบสำหรับสายเทคโนโลยี
- **วัสดุ/เครื่องมือที่ต้องเตรียม:** คอมพิวเตอร์, โปรแกรมออกแบบออฟไลน์ (LibreOffice Impress / Draw.io) [เสริม] / Static HTML / Markdown Portfolio บน NAS [เสริม] / เอกสาร Markdown บน NAS [เสริม]
- **คำถามสะท้อนคิดปิดคาบ:**

### คาบที่ 36: เขียน Reflection และข้อความแนะนำตนเองสำหรับศึกษาต่อ
- **จุดประสงค์การเรียนรู้:**
  1. เขียนบทสะท้อนการเรียนรู้ (Reflection) ตลอดหลักสูตร AI & Robotics อย่างลึกซึ้งและเห็นพัฒนาการของตนเองได้
  2. เรียบเรียงข้อความแนะนำตนเอง / เรียงความจุดมุ่งหมายในการศึกษาต่อ (Statement of Purpose / Self-Introduction 1 หน้า) ได้
- **แนวคิดหลัก:** Statement of Purpose ที่ดีเชื่อมโยง **"อดีต (สิ่งที่เคยสร้างและบทเรียนที่เจอ) → ปัจจุบัน (ทักษะและความหลงใหล) → อนาคต (เป้าหมายในคณะ/สายอาชีพ)"**
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | แสดงตัวอย่าง Statement of Purpose 1 หน้า ที่น่าประทับใจ |
  | 5–12 นาที | บรรยาย/สาธิต | อธิบายโครงสร้างเชื่อมโยง Past → Present → Future |
  | **12–50 นาที (76%)** | **โครงงานปลายคาบ** | ลงมือเขียน Reflection & ข้อความแนะนำตนเอง 1 หน้า |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** บทความแนะนำตนเองและสะท้อนการเรียนรู้ (1-Page SOP & Reflection)
  - **โจทย์/สถานการณ์:** เขียนข้อความแนะนำตนเอง 1 หน้าสำหรับนำไปใส่ในคำนำ/หน้าประวัติของ Portfolio และสมัครศึกษาต่อ
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** เอกสารข้อความ 1 หน้า (LibreOffice Writer / Markdown [เสริม] / ใส่ใน Portfolio) ครอบคลุม: แรงบันดาลใจ, จุดเปลี่ยนสำคัญจากการเรียน AI & Robotics (เล่าความล้มเหลวที่เคยแก้สำเร็จ 1 เรื่อง), ทักษะที่ภูมิใจ, และเป้าหมายอนาคต
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. ทบทวนการเดินทางตั้งแต่ ม.4/1 จนถึง ม.6/2
    2. ร่างย่อหน้า 1: แรงบันดาลใจและตัวตน, ย่อหน้า 2: ประสบการณ์ลงมือทำจริงและบทเรียนจากความผิดพลาด, ย่อหน้า 3: เป้าหมายการเรียนต่อ/อาชีพ
    3. อ่านทวนและขัดเกลาภาษาให้จริงใจ ไม่ใช้คำหรูเกินจริง
    4. นำไปใส่ในหน้าแนะนำตัวของ Portfolio
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - เล่าเรื่องเชื่อมโยงอดีต–ปัจจุบัน–อนาคตได้ลื่นไหล (4 คะแนน)
    - สะท้อนบทเรียนจากประสบการณ์จริงอย่างลึกซึ้งและจริงใจ (4 คะแนน)
    - ภาษาถูกต้อง กระชับ จบใน 1 หน้า (2 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** ข้อความ 1 หน้าเล่าเรื่องจริงตอนต่อวงจร ESP32-S3 พังใน ม.4 จนถึงวันที่สร้างระบบ AIoT/Capstone สำเร็จ และเชื่อมสู่เป้าหมายเรียนต่อวิศวะ/วิทยาการคอมพิวเตอร์
  - **ตัวเลือกเสริม (Extension):** แปลเป็นฉบับภาษาอังกฤษ 1 หน้าสำหรับยื่นหลักสูตรนานาชาติ
  - **แนวทางช่วยเหลือ (Scaffold):** แจกคำถามกระตุ้นความคิด 4 ข้อเพื่อช่วยเขียนแต่ละย่อหน้า
- **วัสดุ/เครื่องมือที่ต้องเตรียม:** คอมพิวเตอร์, LibreOffice Writer / Markdown [เสริม]
- **คำถามสะท้อนคิดปิดคาบ:**
  1. ความผิดพลาดครั้งไหนตลอด 3 ปีที่สอนบทเรียนที่มีค่าที่สุดให้กับคุณ?

### คาบที่ 37: ซ้อมนำเสนอและถาม–ตอบ (Mock Panel)
- **จุดประสงค์การเรียนรู้:**
  1. ซ้อมนำเสนอ Final Presentation (ครอบคลุมเทคนิค + สาธิต + ธุรกิจ + ผลทดสอบจริง) ต่อหน้ากรรมการจำลองได้
  2. รับมือคำถามเชิงลึกจาก Mock Panel และเตรียมแผนรับมือ Q&A สำหรับวันนำเสนอจริงได้
- **แนวคิดหลัก:** Mock Panel จำลองบรรยากาศความกดดันและคำถามยากจากกรรมการผู้เชี่ยวชาญ เพื่อไม่ให้ทีมตื่นสนามในวัน Final Presentation (คาบ 38–39)
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/จัดเวที | เชิญครู/เพื่อนตัวแทนรับบท Mock Panel และแจ้งกติกาจับเวลา |
  | **5–42 นาที (74%)** | **โครงงานปลายคาบ (Mock Panel)** | แต่ละทีมซ้อมนำเสนอ + สาธิตสั้น + ตอบคำถามกรรมการจำลอง |
  | 42–50 นาที | สรุปคำแนะนำ | สรุปจุดที่ต้องซ่อม/เตรียมคำตอบก่อนคาบ 38–39 |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** การซ้อมใหญ่หน้ากรรมการจำลอง (Mock Panel & Q&A Prep)
  - **โจทย์/สถานการณ์:** ทดสอบการนำเสนอ + สาธิตระบบ `v2.0` + ตอบคำถามเชิงลึก (เทคนิค ธุรกิจ จริยธรรม) ต่อหน้าคณะกรรมการจำลอง
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** (1) สไลด์ Final Presentation ฉบับพร้อมแข่ง (รวมผล Sprint 4–5 และ UAT รอบ 2 ล่าสุดแล้ว), (2) บันทึกคำแนะนำและรายการคำถามยากที่โดนถามใน Mock Panel พร้อมแนวคำตอบ
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. นำเสนอตามเวลาจริง + สาธิตระบบสด
    2. รับคำถามกดดันจาก Mock Panel (เช่น "ถ้าข้อมูลเปลี่ยนจะทำไง?", "ทำไมลูกค้าต้องจ่ายเงิน?", "PDPA จัดการยังไง?")
    3. จดคำแนะนำและคำถามที่ยังตอบตะกุกตะกักไปซ้อมตอบเพิ่ม
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**

    - การนำเสนอและสาธิตเป็นมืออาชีพ (3 คะแนน)
    - ตอบคำถาม Mock Panel อย่างมีสติและจดปรับปรุง (3 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** สาธิตผ่านฉลุย รับฟีดแบ็กเรื่อง "ให้โชว์สไลด์ Benchmark เทียบ ม.6/1 ชัดขึ้นอีกนิด" และจดแนวตอบคำถามเรื่องการขยายผล
  - **ตัวเลือกเสริม (Extension):** เตรียมสไลด์ Appendix เพิ่มเติมสำหรับคำถามที่ถูกถามใน Mock Panel
  - **แนวทางช่วยเหลือ (Scaffold):** เตรียมคลังคำถาม Mock Panel 10 ข้อ (สายเทคนิค 5 + สายธุรกิจ 5) ให้กรรมการจำลองใช้ถาม

### คาบที่ 38: Final Presentation (รอบที่ 1) — นำเสนอและสาธิตต่อคณะกรรมการ/ผู้เชี่ยวชาญ
- **จุดประสงค์การเรียนรู้:**
  1. นำเสนอโครงงาน Capstone ฉบับสมบูรณ์ (ปัญหา นวัตกรรม สถาปัตยกรรม ผล Benchmark/UAT และโมเดลธุรกิจ) ต่อคณะกรรมการ/ผู้เชี่ยวชาญได้อย่างมั่นใจ
  2. สาธิตการทำงานจริงของผลิตภัณฑ์และตอบคำถามเชิงลึกด้วยหลักฐานทางวิศวกรรมและธุรกิจได้
- **แนวคิดหลัก:** Final Presentation คือเวทีแสดงศักยภาพสูงสุดของผู้เรียนตลอดหลักสูตร 3 ปี ต่อหน้าคณะกรรมการและผู้เชี่ยวชาญ
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดงาน/แนะนำกรรมการ | ต้อนรับคณะกรรมการ/ผู้เชี่ยวชาญ ชี้แจงเกณฑ์และลำดับนำเสนอ (ครึ่งแรกของห้อง) |
  | **5–45 นาที (80%)** | **โครงงานปลายคาบ (Final Presentation รอบ 1)** | ทีมกลุ่มที่ 1 นำเสนอ + สาธิตสด + Q&A ต่อคณะกรรมการ |
  | 45–50 นาที | สรุปช่วงที่ 1 | คณะกรรมการให้ข้อเสนอแนะภาพรวมรอบที่ 1 |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** Capstone Final Presentation Showcase (รอบที่ 1)
  - **โจทย์/สถานการณ์:** ทีมครึ่งแรกขึ้นนำเสนอและสาธิตสด Capstone Project ฉบับสมบูรณ์ต่อหน้าคณะกรรมการ/ผู้เชี่ยวชาญ (ทีมที่ยังไม่นำเสนอทำหน้าที่ผู้สังเกตการณ์และบันทึกข้อคิด)
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** (1) การนำเสนอและสาธิตสดของทีมรอบที่ 1 (ตามเวลามาตรฐาน เช่น 5 นาทีนำเสนอ/สาธิต + 3 นาที Q&A), (2) ใบสรุปคำแนะนำจากกรรมการ / บันทึกการเรียนรู้สำหรับทีมผู้ฟัง
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. ทีมรอบที่ 1 ตั้งชุด Demo Kit และนำเสนอครบวงจร + ตอบคำถามกรรมการ
    2. ทีมรอบที่ 2 สังเกตการณ์และจดประเด็นคำถาม/คำแนะนำจากผู้เชี่ยวชาญเพื่อเรียนรู้
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - ความสมบูรณ์ของนวัตกรรมและการสาธิตสดที่ใช้งานได้จริง (4 คะแนน)
    - ความชัดเจนในการนำเสนอทั้งมิติเทคนิคและธุรกิจ (3 คะแนน)
    - การตอบคำถามคณะกรรมการด้วยข้อมูลและเหตุผล (3 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** นำเสนอครบทุกมิติ สาธิตสดทำงานจริง 100% และตอบคำถามผู้เชี่ยวชาญได้อย่างมั่นใจและสุภาพ
  - **ตัวเลือกเสริม (Extension):** จัดบูธ/โต๊ะตั้งชิ้นงานให้ผู้เชี่ยวชาญเดินสัมผัสทดลองใช้จริงช่วงพักหรือท้ายคาบ
  - **แนวทางช่วยเหลือ (Scaffold):** หากเน็ต/อุปกรณ์ขัดข้องกะทันหัน อนุญาตให้สลับเปิดคลิป Dry Run สำรองได้ทันทีโดยมีผู้ช่วยคอยกดสไลด์
- **วัสดุ/เครื่องมือที่ต้องเตรียม:** โปรเจกเตอร์, ไมโครโฟน, นาฬิกาจับเวลา, ใบรูบริกคะแนนสำหรับคณะกรรมการ
- **คำถามสะท้อนคิดปิดคาบ:**
  1. ข้อเสนอแนะจากผู้เชี่ยวชาญในรอบที่ 1 ให้มุมมองใหม่อะไรแก่ผู้ฟังทุกคน?

### คาบที่ 39: Final Presentation (รอบที่ 2) — นำเสนอและสาธิตต่อคณะกรรมการ/ผู้เชี่ยวชาญ

  | ช่วงเวลา | กิจกรรม | วิธีสอน |

  | 0–5 นาที | เปิดคาบ/เตรียมระบบ | เตรียมระบบทีมครึ่งหลังและต้อนรับกรรมการ |

  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**

    - ความชัดเจนในการนำเสนอทั้งมิติเทคนิคและธุรกิจ (3 คะแนน)

  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** ทุกทีมนำเสนอจบสมบูรณ์ สาธิตได้จริง และเก็บข้อเสนอแนะจากผู้เชี่ยวชาญครบถ้วน
