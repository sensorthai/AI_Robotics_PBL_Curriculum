# ม.6 ภาคเรียนที่ 2: Future AI Entrepreneur (40 คาบ)

**คำอธิบายรายวิชา:** การเป็นผู้ประกอบการและการเตรียมความพร้อมสู่อนาคต  
**เครื่องมือ/อุปกรณ์:** AI Server (Local Git Server, JupyterHub, Ollama + Open WebUI), NAS Storage, โปรแกรมทำสไลด์/เอกสาร/เว็บพอร์ตโฟลิโอ (LibreOffice/HTML-Markdown `[เสริม]`), Bambu Lab A1 Mini (3D Printer), ชุดอุปกรณ์ตามโครงงานของทีม

## ตารางสรุปภาพรวม 40 คาบ

| คาบที่ | ชื่อคาบ | แนวคิดหลัก | โครงงานปลายคาบ |
|---|---|---|---|
| 1 | ผู้ประกอบการ สตาร์ทอัพ และตัวอย่างธุรกิจ AI | Entrepreneurial Mindset & Startup Lifecycle | แผ่นวิเคราะห์สตาร์ทอัพ AI (ปัญหา-โมเดล-การเติบโต) |

| 3 | Lean โปรแกรมออกแบบออฟไลน์ (LibreOffice Impress / Draw.io) [เสริม]s (2/2): ช่องทาง ตัววัด และจุดได้เปรียบ | Key Metrics, Channels, Unfair Advantage ครบ 9 ช่อง | Lean โปรแกรมออกแบบออฟไลน์ (LibreOffice Impress / Draw.io) [เสริม]s ฉบับสมบูรณ์ 9 ช่องของทีม |

| 5 | ต้นทุน ราคา และโครงสร้างรายได้ (1/2) | Fixed/Variable Cost, Pricing Strategy | ตารางประมาณการต้นทุนและตั้งราคาสินค้า/บริการ |
| 6 | จุดคุ้มทุนเบื้องต้นและการเงินอย่างง่าย (2/2) | Break-even Point และกระแสเงินสดย่อ 6 เดือน | ตารางการเงินอย่างง่ายพร้อมคำนวณจุดคุ้มทุนของทีม |
| 7 | ทรัพย์สินทางปัญญา ลิขสิทธิ์ซอฟต์แวร์ และ PDPA | IP, Open-source License, ข้อมูลส่วนบุคคลเบื้องต้น | ใบงานตรวจความเสี่ยง IP และ PDPA ของโครงงานทีม |
| 8 | โมเดลรายได้และแหล่งทุน (ประกวด/ทุนเยาวชน) | Revenue Model & Grant/Competition Funding | รายการแหล่งทุน/เวทีประกวดที่เหมาะกับทีม ≥ 3 แห่ง |
| 9 | การทำงานเป็นทีมและการจัดการเวลา | Timeboxing, Eisenhower Matrix และตารางงานทีม | แผนบริหารเวลาและตาราง Milestone ประจำเทอมของทีม |
| 10 | การสื่อสารเชิงเทคนิค: อีเมลและรายงานกระชับ | โครงสร้างอีเมลทางการและ Executive Summary | อีเมลสรุปผลงาน/ขอความร่วมมือฉบับใช้งานจริง |
| 11 | ให้–รับข้อเสนอแนะและจัดการความขัดแย้ง | Constructive Feedback (SBI) & Conflict Resolution | บทวิเคราะห์และสคริปต์แก้สถานการณ์ความขัดแย้งในทีม |
| 12 | ร่องรอยดิจิทัลและโปรไฟล์วิชาชีพที่เหมาะกับวัย | Digital Footprint, Local Git Server/LinkedIn/Portfolio Profile | โปรไฟล์วิชาชีพออนไลน์ (Local Git Server/Resume/Bio) ฉบับปรับปรุง |
| 13 | เตรียมสมัครเรียนต่อ: สัมภาษณ์และแฟ้มผลงาน | การเล่าเรื่องโครงงานด้วยเทคนิค STAR | บทซ้อมสัมภาษณ์สั้น (1–2 นาที) + ฟีดแบ็กคู่ซ้อม |
| 14 | โครงสร้าง Pitch: ปัญหา–ทางออก–ตลาด–สาธิต–ข้อเสนอ | องค์ประกอบ Pitch Deck 5 ส่วนหลัก | ใบวิจารณ์ตัวอย่าง Pitch 2 คลิป + โครงเรื่อง Pitch ทีม |
| 15 | เขียนสคริปต์ 3 นาทีและออกแบบสไลด์ Pitch | One-idea-per-slide และการคุมคำพูดไม่เกิน ~400 คำ | สคริปต์ 3 นาที + สไลด์ Pitch Deck ฉบับร่าง |
| 16 | เทคนิคการพูด ภาษากาย และการคุมเวลา | น้ำเสียง การสบตา จังหวะหยุด และ Timing Check | คลิป/บันทึกฝึกพูดเป็นคู่ที่คุมเวลาได้พอดี 3 นาที |
| 17 | ซ้อม Pitch กลุ่มย่อย (รอบที่ 1) | การซ้อมนำเสนอจริงและรับ Peer Critique | บันทึกข้อเสนอแนะจากเพื่อน + แผนแก้สไลด์ |
| 18 | ซ้อม Pitch ต่อหน้าชั้น (รอบที่ 2) และปรับปรุง | การนำเสนอหน้าชั้นและขัดเกลาสไลด์ให้คม | สไลด์ Pitch Deck และสคริปต์ฉบับปรับปรุง |
| 19 | Pitch รอบคัดเลือก (Business & Product Pitch) | การนำเสนอจริงภายใต้เวลาจำกัดและการตอบคำถาม | การ Pitch 3 นาที + คะแนนประเมินรอบคัดเลือก |
| 20 | ทบทวนข้อเสนอแนะจาก ม.6/1 และวางแผนปิดงาน | การรวมฟีดแบ็ก ม.6/1 + ตลาด + Pitch สู่แผนปิดงาน | แผนปิดงาน Capstone (Sprint 4–5 Execution Plan) |
| 21 | Sprint 4 (1/4): เพิ่มความถูกต้องและประสิทธิภาพ (AI/Data) | การยกระดับคุณภาพโมเดลและข้อมูลตามข้อเสนอแนะ | โมเดล/ข้อมูลที่ปรับปรุงรอบใหม่ (Sprint 4 Day 1) |
| 22 | Sprint 4 (2/4): ปรับปรุงฟีเจอร์หลักและฮาร์ดแวร์ | การแก้จุดอ่อนทางเทคนิคและเพิ่มประสิทธิภาพ | ต้นแบบรุ่นปรับปรุงที่แก้จุดอ่อนหลักแล้ว |
| 23 | Sprint 4 (3/4): ปรับปรุง UX/UI และความเร็วตอบสนอง | การลด Latency และปรับหน้าจอตามฟีดแบ็ก | ต้นแบบรุ่นปรับปรุงที่ใช้งานลื่นไหลขึ้น |
| 24 | Sprint 4 (4/4): ทดสอบเปรียบเทียบกับรุ่น ม.6/1 | Benchmark ก่อน–หลัง (Accuracy / Speed / UX) | ต้นแบบรุ่นปรับปรุง + ตารางเทียบผล ม.6/1 vs ม.6/2 |
| 25 | ทบทวน Sprint 4 (Sprint 4 Review) | การเดโมรุ่นปรับปรุงและตรวจรับความพร้อมก่อน Sprint 5 | บันทึกการทบทวน Sprint 4 + แผน Sprint 5 |
| 26 | Sprint 5 (1/3): ยกระดับความเสถียรและความปลอดภัย | Error Handling, Security, PDPA Notice, Fail-Safe | ระบบที่มีมาตรการเสถียรภาพและความปลอดภัยครบ |
| 27 | Sprint 5 (2/3): ทดสอบกับผู้ใช้จริงรอบที่ 2 (UAT Round 2) | การทดสอบยืนยันผลกับผู้ใช้จริงรอบสุดท้าย | บันทึกผลทดสอบผู้ใช้จริงรอบที่ 2 |
| 28 | Sprint 5 (3/3): เก็บตกจุดบกพร่องจาก UAT รอบ 2 | การปิดบั๊กที่พบและล็อกความเสถียรของระบบ | ต้นแบบฉบับเสถียรพร้อมใช้งานจริง |
| 29 | เอกสารฉบับสมบูรณ์ (1/2): รายงานพัฒนาและคู่มือผู้ใช้ | Technical Report & End-User Manual | รายงานพัฒนาฉบับสมบูรณ์ + คู่มือใช้งาน |
| 30 | เอกสารฉบับสมบูรณ์ (2/2): โค้ดใน Repo และ README | Clean Code, License, Requirements, README | Local Git Repo ฉบับสมบูรณ์พร้อม README ที่รันตามได้ |
| 31 | Feature Freeze (1/2): ปิดฟีเจอร์และเตรียมชุดสาธิต | กฎห้ามแก้ฟีเจอร์ใหญ่หลัง Freeze และเตรียม Data/อุปกรณ์ | ระบบที่ Feature Freeze แล้วพร้อมชุดสาธิต |
| 32 | Feature Freeze (2/2): ซ้อมสาธิตครบวงจร (Dry Run) | การซ้อมรันจริงจับเวลาและเตรียมคลิปสำรอง | บันทึกผลการซ้อม Dry Run + คลิปสำรอง |
| 33 | Technical Review ต่อหน้าครู (ตรวจรับทางเทคนิค) | การตรวจโค้ด ฮาร์ดแวร์ ความปลอดภัย และเอกสาร | ใบรับรองผล Technical Review จากครู |
| 34 | จัดทำพอร์ตโฟลิโอ (1/2): โครงสร้าง ภาพ วิดีโอ และบทบาท | การเล่าเรื่องผลงานส่วนตัวในพอร์ตโฟลิโอ | โครงร่างพอร์ตโฟลิโอรายบุคคลพร้อมภาพ/วิดีโอ |
| 35 | จัดทำพอร์ตโฟลิโอ (2/2): ประกอบพอร์ตโฟลิโอแบบเว็บ/เอกสาร | การจัดวางผลงาน ผลทดสอบ และบทบาทตนเองให้โดดเด่น | พอร์ตโฟลิโอแบบเว็บหรือเอกสาร PDF รายบุคคล |
| 36 | เขียน Reflection และข้อความแนะนำตนเองสำหรับศึกษาต่อ | Statement of Purpose / Self-Reflection 1 หน้า | เอกสาร Reflection & คำแนะนำตนเอง 1 หน้า |
| 37 | ซ้อมนำเสนอและถาม–ตอบ (Mock Panel) | การรับมือคำถามเชิงลึกจากกรรมการจำลอง | บันทึกข้อเสนอแนะจาก Mock Panel + แผนรับมือ Q&A |
| 38 | Final Presentation (รอบที่ 1): นำเสนอและสาธิตต่อกรรมการ | การนำเสนอและสาธิตสดระดับมืออาชีพ | การนำเสนอ + สาธิตสดต่อคณะกรรมการ/ผู้เชี่ยวชาญ |
| 39 | Final Presentation (รอบที่ 2): นำเสนอและสาธิตต่อกรรมการ | การนำเสนอและสาธิตสด + แลกเปลี่ยนเรียนรู้ | การนำเสนอ + สาธิตสด + ข้อเสนอแนะจากผู้เชี่ยวชาญ |
| 40 | สรุปหลักสูตร 3 ปีและแผนต่อยอดรายบุคคล | Lifelong Learning Roadmap (ศึกษาต่อ / ประกวด / ธุรกิจ) | แผนต่อยอดรายบุคคล (Individual Future Roadmap) |

## โครงงานรวบยอดประจำภาคเรียนและตลอดหลักสูตร
**Capstone Project ฉบับสมบูรณ์ พร้อม Portfolio และการนำเสนอผลงาน**:
- ต่อยอดต้นแบบจาก ม.6/1 ด้วยโมเดลธุรกิจ **Lean โปรแกรมออกแบบออฟไลน์ (LibreOffice Impress / Draw.io) [เสริม]s, การเงิน, IP/PDPA และ Pitching** ใน **Unit 1–3 (คาบ 1–19)**
- ยกระดับต้นแบบใน **Sprint 4–5** จนเสถียร ปลอดภัย มีเอกสารและ Local Git Repo ครบถ้วนใน **Unit 4 (คาบ 20–33)**
- สรุปเป็น **Portfolio รายบุคคล** และนำเสนอใน **Final Presentation (Unit 5, คาบ 34–40)**
