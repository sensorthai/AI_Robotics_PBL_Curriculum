### คาบที่ 6: จาก ML สู่ DL และเซลล์ประสาทเทียม (Neural Network)
- **จุดประสงค์การเรียนรู้:**
  1. อธิบายโครงสร้างพื้นฐานของเซลล์ประสาทเทียม (Input, Weight, Bias, Activation, Output) แบบเข้าใจง่ายได้
  2. ทดลองปรับโครงสร้างโครงข่ายประสาทเทียมเพื่อจำแนกข้อมูลแบบไม่เป็นเส้นตรงบน สคริปต์จำลองโครงข่ายประสาทเทียมบน JupyterHub ได้
- **แนวคิดหลัก:** เซลล์ประสาทเทียม (Perceptron) รับค่าอินพุตมาคูณค่าน้ำหนัก (Weight) บวกค่าอคติ (Bias) แล้วผ่านฟังก์ชันกระตุ้น (Activation) เมื่อนำมาต่อกันหลายชั้นจะเรียนรู้รูปแบบที่ซับซ้อนได้
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | แสดงข้อมูลรูปวงกลมซ้อนกัน 2 วง แล้วถามว่าเส้นตรงเส้นเดียวแบ่งได้ไหม |
  | 5–15 นาที | บรรยาย/สาธิต | อธิบายหลักการของ Neuron และสาธิตเว็บ สคริปต์จำลองโครงข่ายประสาทเทียมบน JupyterHub |
  | 15–25 นาที | ฝึกปฏิบัติแบบมีผู้ช่วย | ลองฝึกข้อมูลแบบง่าย (2 กลุ่มแยกชัด) ด้วย 0 Hidden Layer บน Playground |
  | **25–50 นาที (50%)** | **โครงงานปลายคาบ** | ลงมือทำเอง |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** ภารกิจพิชิตข้อมูลเกลียว (สคริปต์จำลองโครงข่ายประสาทเทียมบน JupyterHub Challenge)
  - **โจทย์/สถานการณ์:** ทดลองออกแบบโครงข่ายประสาทเทียมบน สคริปต์จำลองโครงข่ายประสาทเทียมบน JupyterHub ให้สามารถแยกข้อมูลที่ซับซ้อน (เช่น รูปวงกลมซ้อน และรูปเกลียว Spiral) โดยใช้จำนวนชั้นและนิวรอนให้น้อยที่สุดเท่าที่จำเป็น
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** เอกสารบันทึกการทดลอง (ภาพแคปหน้าจอ + ตารางสรุป) ครบ 2 ด่าน (Circle และ Spiral) ระบุจำนวน Hidden Layers, จำนวน Neurons, Activation ที่ใช้ และค่า Test Loss ที่ได้
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. รันสคริปต์จำลองโครงข่ายประสาทเทียมบน JupyterHub เลือกชุดข้อมูล **Circle** ทดลองแบบ 0 Hidden Layers (สังเกตว่าทำไม่ได้) แล้วเพิ่ม Hidden Layer จนแยกได้ (Test Loss < 0.05)
    2. เปลี่ยนเป็นชุดข้อมูลที่ยากขึ้น **Spiral** ทดลองปรับเพิ่มจำนวนชั้น, จำนวนนิวรอน, และฟีเจอร์
    3. แคปภาพโครงข่ายที่สำเร็จทั้ง 2 ด่านและจดบันทึกการสังเกต
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - แก้โจทย์ Circle และ Spiral ให้โมเดลแยกคลาสได้สำเร็จ (4 คะแนน)
    - อธิบายผลของการเพิ่ม Hidden Layers และ Neurons ได้ถูกต้อง (3 คะแนน)
    - บันทึกค่าพารามิเตอร์และ Test Loss ครบถ้วน (3 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** ด่าน Circle ใช้ 1 Hidden Layer (3–4 neurons, ReLU) ได้ Loss 0.01; ด่าน Spiral ใช้ 3–4 Hidden Layers แยกเส้นเกลียวได้ชัด
  - **ตัวเลือกเสริม (Extension):** ลองเปิด Noise ใน Playground เป็น 20% แล้วดูว่าถ้าใส่นิวรอนเยอะเกินไปจะเกิด Overfitting บนภาพพื้นหลังอย่างไร
  - **แนวทางช่วยเหลือ (Scaffold):** เตรียมตารางบันทึก 2 ด่านและคำแนะนำเบื้องต้นสำหรับชุด Spiral (เช่น ลองใช้ `ReLU` หรือ `Tanh`)
- **วัสดุ/เครื่องมือที่ต้องเตรียม:** คอมพิวเตอร์, อินเทอร์เน็ต, เว็บไซต์ สคริปต์จำลองโครงข่ายประสาทเทียมบน JupyterHub
- **คำถามสะท้อนคิดปิดคาบ:**
  1. ทำไมโครงข่ายที่ไม่มี Hidden Layer เลยถึงแยกข้อมูลรูปวงกลมซ้อนหรือเกลียวไม่ได้?
  2. การเพิ่มจำนวนชั้นและนิวรอนมากเกินความจำเป็นมีข้อเสียอย่างไร?

### คาบที่ 7: โครงข่ายหลายชั้นและ Activation Functions
- **จุดประสงค์การเรียนรู้:**
  1. อธิบายบทบาทของ Hidden Layers และ Activation Functions ยอดนิยม (ReLU, Sigmoid, Softmax) ในเชิงแนวคิดได้
  2. เลือกใช้ Activation Function ให้เหมาะสมกับเลเยอร์ซ่อนและเลเยอร์ผลลัพธ์ (Output Layer) ได้
- **แนวคิดหลัก:** Activation Function ทำให้โครงข่ายประสาทเรียนรู้ความสัมพันธ์ที่ไม่เป็นเส้นตรงได้ โดย `ReLU` นิยมใช้ในชั้นซ่อน ส่วน `Sigmoid/Softmax` ใช้แปลงผลลัพธ์ชั้นสุดท้ายเป็นความน่าจะเป็น
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | ทบทวนผลจาก Playground: ลองเปลี่ยน Activation เป็น Linear จะเกิดอะไรขึ้น |
  | 5–15 นาที | บรรยาย/สาธิต | อธิบาย ReLU, Sigmoid (2 คลาส), Softmax (หลายคลาส) และโครงสร้าง MLP ขนาดเล็ก |
  | 15–25 นาที | ฝึกปฏิบัติแบบมีผู้ช่วย | เขียนโค้ดจำลอง `relu(x)` และดูกราฟด้วย Python สั้น ๆ |
  | **25–50 นาที (50%)** | **โครงงานปลายคาบ** | ลงมือทำเอง |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** ออกแบบสถาปัตยกรรมโครงข่ายและสร้างโมเดลทำนายขนาดเล็ก
  - **โจทย์/สถานการณ์:** สร้างโครงข่ายประสาทขนาดเล็กด้วย `Sequential` ของ PyTorch เพื่อจำแนกข้อมูลตาราง 3 คลาส (เช่น ชุดข้อมูล Iris) พร้อมกำหนด Activation Function ให้ถูกต้องทุกชั้น
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** Jupyter Notebook (บน JupyterHub) ที่มีโค้ดสร้างโครงข่ายประสาทขนาดเล็ก (`Dense` ≥ 2 ชั้น ใช้ `relu` และ `softmax`) แสดง `model.summary()` และทดลองทำนายผลลัพธ์
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. โหลดชุดข้อมูล Iris และแบ่ง Train/Test
    2. สร้างโมเดล `torch.nn.Sequential([Dense(16, activation='relu'), Dense(8, activation='relu'), Dense(3, activation='softmax')])`
    3. รัน `model.summary()` เพื่อดูจำนวน Parameters ในแต่ละชั้น
    4. คอมไพล์ ฝึก 30 epochs และดูผลความน่าจะเป็นจาก Softmax
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - เลือก Activation Function ในชั้นซ่อนและชั้น Output ถูกต้อง (4 คะแนน)
    - โมเดลฝึกและทำนายผลออกมาเป็นความน่าจะเป็นรวมกันได้ 1.0 (3 คะแนน)
    - อธิบายความหมายของ `model.summary()` ได้ (3 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** Output แสดง `array([0.02, 0.95, 0.03])` → ทำนายคลาส 1 ด้วยความมั่นใจ 95%
  - **ตัวเลือกเสริม (Extension):** ลองเปลี่ยนจำนวนนิวรอนในชั้นซ่อนแล้วสังเกต `Total params` ใน `model.summary()`
  - **แนวทางช่วยเหลือ (Scaffold):** แจกตารางคู่มือเลือก Output Activation (Regression = Linear, 2 คลาส = Sigmoid, ≥3 คลาส = Softmax)
- **วัสดุ/เครื่องมือที่ต้องเตรียม:** คอมพิวเตอร์, JupyterHub บน AI Server
- **คำถามสะท้อนคิดปิดคาบ:**
  1. ทำไมชั้น Output ของงานจำแนก 3 คลาสจึงต้องใช้ Softmax?
  2. ถ้าไม่ใส่ Activation Function ใน Hidden Layer เลย โครงข่าย 10 ชั้นจะต่างจากโมเดลเชิงเส้นชั้นเดียวหรือไม่?

### คาบที่ 8: Loss Function และ Optimizer (โมเดลเรียนรู้ได้อย่างไร)
- **จุดประสงค์การเรียนรู้:**
  1. อธิบายบทบาทของ Loss Function (วัดความผิดพลาด) และ Optimizer (ปรับ Weight เพื่อลด Loss) ในเชิงแนวคิดได้
  2. ทดลองปรับ Optimizer (`SGD`, `Adam`) และ Learning Rate แล้วสังเกตผลต่อการเรียนรู้ของโมเดลได้
- **แนวคิดหลัก:** การเรียนรู้ของ Deep Learning คือการเดินลงเขา (Gradient Descent) เพื่อหาจุดที่ Loss ต่ำที่สุด โดยมี Optimizer เป็นผู้กำหนดวิธีเดินและ Learning Rate เป็นขนาดก้าวเดิน
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | อุปมาการเดินลงเขาในหมอก (Loss = ความสูง, Learning Rate = ขนาดก้าว) |
  | 5–15 นาที | บรรยาย/สาธิต | อธิบาย Loss (`categorical_crossentropy` / `mse`) และ Optimizer (`SGD` vs `Adam`) |
  | 15–25 นาที | ฝึกปฏิบัติแบบมีผู้ช่วย | ทดลองตั้ง Learning Rate สูงมาก (เช่น `1.0`) vs ต่ำมาก (`0.00001`) บนโมเดลเล็ก |
  | **25–50 นาที (50%)** | **โครงงานปลายคาบ** | ลงมือทำเอง |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** ห้องทดลองจูน Optimizer & Learning Rate
  - **โจทย์/สถานการณ์:** นำโครงข่ายขนาดเล็กจากคาบ 7 มาทดลองเปลี่ยน Optimizer และ Learning Rate 3 ค่า เพื่อหาค่าที่ทำให้โมเดลเรียนรู้เร็วและแม่นยำที่สุด
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** Jupyter Notebook (บน JupyterHub) + กราฟเปรียบเทียบเส้น Loss 3 เส้น (เช่น `SGD lr=0.01`, `Adam lr=0.001`, `Adam lr=0.5`) พร้อมข้อสรุปผลกระทบของ Learning Rate
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. ใช้โครงสร้างโมเดลและข้อมูลจากคาบ 7
    2. สร้างฟังก์ชันฝึกโมเดลที่รับค่า `optimizer` และเก็บ `history.history['loss']`
    3. ทดสอบ 3 รูปแบบ: (1) `Adam(0.001)`, (2) `Adam(0.5)` (ก้าวใหญ่ไป), (3) `SGD(0.001)` (ก้าวช้า)
    4. พล็อตกราฟ Loss ทั้ง 3 เส้นบนกราฟเดียวกันเพื่อเปรียบเทียบ
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - ทดสอบครบ 3 การตั้งค่า Optimizer/LR (4 คะแนน)
    - พล็อตกราฟ Loss เปรียบเทียบได้ชัดเจน (3 คะแนน)
    - อธิบายอาการก้าวใหญ่เกินไป (Loss แกว่ง/ไม่ลด) และก้าวเล็กเกินไป (เรียนรู้ช้า) ได้ (3 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** กราฟแสดงเส้น `Adam(0.001)` ลดลงราบรื่นเร็วที่สุด ส่วน `Adam(0.5)` กระโดดขึ้นลง
  - **ตัวเลือกเสริม (Extension):** ทดลองปรับ Batch Size (เช่น `8` vs `64`) แล้วดูความเร็วและเส้น Loss
  - **แนวทางช่วยเหลือ (Scaffold):** เตรียมโค้ดฟังก์ชัน `train_with_opt(opt)` ให้เรียกใช้ซ้ำ 3 ครั้ง
- **วัสดุ/เครื่องมือที่ต้องเตรียม:** คอมพิวเตอร์, JupyterHub บน AI Server (ต่อยอดจากคาบ 7)
- **คำถามสะท้อนคิดปิดคาบ:**
  1. ทำไมการตั้ง Learning Rate สูงเกินไปจึงทำให้โมเดลเรียนรู้ไม่สำเร็จ?
  2. เพราะเหตุใด `Adam` จึงเป็นที่นิยมใช้เป็นค่าเริ่มต้นมากกว่า `SGD` แบบพื้นฐาน?

### คาบที่ 9: สร้างโมเดล PyTorch แรกกับชุดข้อมูลภาพ (MNIST)
- **จุดประสงค์การเรียนรู้:**
  1. โหลดและเตรียมข้อมูลภาพเบื้องต้น (Reshape/Flatten และ Normalize พิกเซลจาก 0–255 เป็น 0–1) ได้
  2. สร้าง ฝึก และประเมินโมเดล PyTorch แรกบนชุดข้อมูลภาพตัวเลขเขียนมือ MNIST ได้
- **แนวคิดหลัก:** ภาพขาว-ดำขนาด 28x28 พิกเซล คือตัวเลขความสว่าง 0–255 การหารด้วย 255.0 (Normalize) ช่วยให้โครงข่ายประสาทเรียนรู้ได้เสถียรและเร็วขึ้น
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | แสดงภาพจากชุดข้อมูล MNIST และตัวเลขพิกเซลจริงข้างใน |
  | 5–15 นาที | บรรยาย/สาธิต | สาธิตโหลด `torchvision.datasets.MNIST`, Normalize (`ToTensor()`), ชั้น `nn.Flatten()`, และ `nn.CrossEntropyLoss()` |
  | 15–25 นาที | ฝึกปฏิบัติแบบมีผู้ช่วย | โหลดข้อมูลและพล็อตดูภาพ MNIST 5 ภาพแรกพร้อมเฉลย |
  | **25–50 นาที (50%)** | **โครงงานปลายคาบ** | ลงมือทำเอง |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** ระบบอ่านตัวเลขเขียนมือ MNIST รุ่นแรก (My First PyTorch Vision Model)
  - **โจทย์/สถานการณ์:** สร้างโมเดล Deep Learning ตัวแรกที่สามารถอ่านลายมือตัวเลข 0–9 (ความแม่นยำ ≥ 95% บนชุดทดสอบ)
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** Jupyter Notebook (บน JupyterHub) ที่ฝึกโมเดล MNIST สำเร็จ วัดผล `model.evaluate(x_test, y_test)` ได้ Accuracy ≥ 95% และแสดงภาพตัวอย่าง 5 ภาพพร้อมคำทำนาย
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. โหลด `(x_train, y_train), (x_test, y_test) = torchvision.datasets.MNIST.load_data()`
    2. Normalize: `x_train, x_test = x_train / 255.0, x_test / 255.0`
    3. สร้าง `Sequential`: `Flatten(input_shape=(28, 28))` → `Dense(128, 'relu')` → `Dense(10, 'softmax')`
    4. คอมไพล์ (`adam`, `sparse_categorical_crossentropy`) และ `fit(..., epochs=5)`

### คาบที่ 13: รู้จัก CNN — Convolution และ Pooling
- **จุดประสงค์การเรียนรู้:**
  1. อธิบายข้อจำกัดของโมเดล Dense (`Flatten`) กับภาพสีและความสำคัญของ CNN (Convolutional Neural Network) ได้
  2. อธิบายหน้าที่ของ `Conv2D` (สกัดลักษณะเด่น) และ `MaxPooling2D` (ลดขนาดและสรุปฟีเจอร์) พร้อมต่อชั้นใน PyTorch ได้
- **แนวคิดหลัก:** `Flatten` ทำลายตำแหน่งเชิงพื้นที่ (Spatial Structure) ของพิกเซล แต่ CNN ใช้ตัวกรอง (Filter/Kernel) กวาดหาขอบและลวดลายในภาพโดยตรง ทำให้จำแนกภาพได้แม่นยำกว่ามาก
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | ทายภาพ: ถ้าเลื่อนตัวเลขไปทางขวา 3 พิกเซล `Flatten+Dense` อาจงง แต่ CNN ยังจำได้ |
  | 5–15 นาที | บรรยาย/สาธิต | แสดงภาพเคลื่อนไหว Convolution Filter 3x3 และ MaxPooling 2x2 |
  | 15–25 นาที | ฝึกปฏิบัติแบบมีผู้ช่วย | สร้างชั้น `Conv2D(32, (3,3))` + `MaxPooling2D((2,2))` และดู `.summary()` |
  | **25–50 นาที (50%)** | **โครงงานปลายคาบ** | ลงมือทำเอง |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** เครื่องสแกนฟีเจอร์ CNN (CNN Feature Extractor)
  - **โจทย์/สถานการณ์:** สร้างส่วนสกัดลักษณะเด่นของ CNN (Convolutional Base) และดูการเปลี่ยนแปลงของขนาดภาพ (Output Shape) ในแต่ละชั้น

- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** ภารกิจสร้างและรายงานผลโมเดลภาพ PyTorch (DL Practical Assessment)
  - **โจทย์/สถานการณ์:** ได้รับชุดข้อมูลภาพ (เช่น `tf_flowers` 5 คลาส หรือ `cats_vs_dogs` ขนาดย่อม) ต้องสร้างโมเดลจำแนกภาพให้ได้ความแม่นยำตามเกณฑ์ พร้อมรายงานวิเคราะห์ผล
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** Jupyter Notebook (บน JupyterHub) ฉบับสมบูรณ์ 1 ไฟล์ ประกอบด้วย: การเตรียมข้อมูล, โมเดล (CNN หรือ MobileNet), กราฟ Train/Val Loss & Accuracy, ค่า Test Accuracy, และสรุปวิเคราะห์ 3 บรรทัด
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. โหลดชุดข้อมูลภาพที่กำหนดและแบ่ง Train/Val/Test
    2. สร้างโมเดล (ใส่ Dropout หรือ EarlyStopping ป้องกัน Overfit)
    3. ฝึกโมเดลบน GPU และพล็อตกราฟ Learning Curve
    4. ประเมิน Test Accuracy และเขียนสรุปจุดที่ควรปรับปรุงต่อ
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - เตรียมข้อมูลและสร้างโมเดลรันผ่านโดยไม่ Error (4 คะแนน)
    - มีกลไกป้องกัน Overfitting และฝึกได้ผลลัพธ์ตามเกณฑ์ (3 คะแนน)
    - พล็อตกราฟและรายงานวิเคราะห์ผลได้ถูกต้อง (3 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** โน้ตบุ๊กรันผ่านทุกเซลล์ กราฟชัดเจน Test Acc ผ่านเกณฑ์ และระบุได้ว่าโมเดล Overfit เล็กน้อยหรือพอดีแล้ว
