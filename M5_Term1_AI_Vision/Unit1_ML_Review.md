### คาบที่ 3: Regression เบื้องต้นและการวัดผล (MAE)
- **จุดประสงค์การเรียนรู้:**
  1. แยกความแตกต่างระหว่างงาน Classification (ทายคลาส) กับ Regression (ทายค่าตัวเลขต่อเนื่อง) ได้
  2. สร้างโมเดล `LinearRegression` ใน `scikit-learn` และวัดความคลาดเคลื่อนด้วย Mean Absolute Error (MAE) ได้
- **แนวคิดหลัก:** Regression ใช้ทำนายค่าตัวเลขต่อเนื่อง (เช่น ราคา อุณหภูมิ คะแนน) โดยวัดความแม่นยำจากระยะห่างระหว่างค่าที่ทายกับค่าจริง เช่น MAE (เฉลี่ยแล้วทายพลาดไปกี่หน่วย)
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | เทียบโจทย์ "ฝนจะตกไหม (Class)" vs "ฝนจะตกกี่มิลลิเมตร (Reg)" |
  | 5–15 นาที | บรรยาย/สาธิต | สอน `LinearRegression` และ `mean_absolute_error(y_test, y_pred)` |
  | 15–25 นาที | ฝึกปฏิบัติแบบมีผู้ช่วย | พล็อตกราฟจุดข้อมูล 1 ตัวแปรพร้อมเส้นตรงทำนายผล |
  | **25–50 นาที (50%)** | **โครงงานปลายคาบ** | ลงมือทำเอง |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** โมเดลทำนายค่าตัวเลขและวัดความคลาดเคลื่อน MAE
  - **โจทย์/สถานการณ์:** สร้างระบบทำนายค่าตัวเลขจากข้อมูลจริง (เช่น ทำนายคะแนนสอบจากชั่วโมงอ่านหนังสือ/ชุดข้อมูล `load_diabetes` หรือชุดข้อมูลราคาบ้าน/ค่าขนม) พร้อมระบุช่วงความคลาดเคลื่อนที่ยอมรับได้
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** Jupyter Notebook (บน JupyterHub) ที่ฝึกโมเดล Regression คำนวณค่า **MAE** บน Test Set วาดกราฟเปรียบเทียบค่าจริง vs ค่าทำนาย (`y_test` vs `y_pred`) และเขียนแปลความหมายค่า MAE เป็นภาษาคน
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. โหลดชุดข้อมูล Regression (เช่น `load_diabetes` หรือ `classroom_data.csv` จาก ม.4)
    2. แบ่ง `train_test_split`
    3. ฝึก `LinearRegression().fit(X_train, y_train)`
    4. คำนวณ `mae = mean_absolute_error(y_test, y_pred)`
    5. วาด Scatter Plot แกน X = ค่าจริง, แกน Y = ค่าทำนาย เพื่อดูว่าใกล้เส้นทแยงมุมแค่ไหน
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - สร้างและฝึกโมเดล Regression ถูกต้อง (4 คะแนน)
    - คำนวณและแปลความหมาย MAE พร้อมหน่วยได้ถูกต้อง (3 คะแนน)
    - วาดกราฟเปรียบเทียบค่าจริง vs ค่าทำนายได้ชัดเจน (3 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** แสดง `MAE = 42.5` พร้อมสรุปว่า *"โดยเฉลี่ยโมเดลทำนายคลาดเคลื่อน ±42.5 หน่วย"* และมีกราฟจุดเกาะแนวทแยงมุม
  - **ตัวเลือกเสริม (Extension):** ลองคำนวณ `R2 Score` (`r2_score`) เพิ่มเติมและอธิบายความหมาย
  - **แนวทางช่วยเหลือ (Scaffold):** เตรียมโค้ดสร้างชุดข้อมูลตัวอย่าง (เช่น ชั่วโมงเรียน vs คะแนน) เผื่อใช้ทดลองก่อนเข้าชุดข้อมูลใหญ่

### คาบที่ 4: Train/Validation/Test, Overfitting และ Cross-Validation
- **จุดประสงค์การเรียนรู้:**
  1. อธิบายบทบาทของการแบ่งข้อมูล 3 ส่วน (Train / Validation / Test) และหลักการของ Cross-Validation ได้
  2. ใช้ `cross_val_score` ตรวจสอบความเสถียรของโมเดลและตรวจจับอาการ Overfitting ได้
- **แนวคิดหลัก:** ถ้าเราปรับจูนโมเดลโดยดูคะแนนจาก Test Set บ่อย ๆ เท่ากับแอบดูข้อสอบ จึงต้องมี Validation Set (หรือ Cross-Validation) สำหรับจูนโมเดล และเก็บ Test Set ไว้สอบจริงครั้งเดียว
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | อุปมา: ชุดฝึก (ทำการบ้าน) → Validation (สอบจำลอง/พรีเทสต์) → Test (สอบจริง) |
  | 5–15 นาที | บรรยาย/สาธิต | อธิบาย 5-Fold Cross-Validation และสาธิต `cross_val_score` |
  | 15–25 นาที | ฝึกปฏิบัติแบบมีผู้ช่วย | รัน `cross_val_score(..., cv=5)` และดูค่าเฉลี่ย ± ส่วนเบี่ยงเบน |
  | **25–50 นาที (50%)** | **โครงงานปลายคาบ** | ลงมือทำเอง |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** ห้องแล็บจับผิดโมเดลฟิตเกิน (Overfitting & Cross-Validation Lab)
  - **โจทย์/สถานการณ์:** ทดสอบปรับความซับซ้อนของ Decision Tree (`max_depth` ตั้งแต่ 1 ถึง 15) เพื่อหาจุดสมดุลที่สุดด้วย Cross-Validation ก่อนนำไปสอบจริงกับ Test Set
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** Jupyter Notebook (บน JupyterHub) ที่มีกราฟเส้นแสดง Train Score vs Validation/CV Score ตามค่า `max_depth` พร้อมชี้จุดที่ Overfit และเลือก `max_depth` ที่ดีที่สุดไปวัดผลบน Test Set
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. แบ่ง Test Set ออก 20% เก็บไว้ห้ามแตะ (เหลือ 80% เป็นชุดฝึก+CV)
    2. วนลูป `max_depth` จาก 1 ถึง 15 เก็บคะแนน `Train Accuracy` และ `5-Fold CV Accuracy`
    3. พล็อตกราฟเส้น 2 เส้นเทียบกันเพื่อดูจุดที่เส้น Train พุ่งขึ้นแต่เส้น CV เริ่มตก
    4. เลือก `max_depth` ที่ให้คะแนน CV สูงสุดมาฝึกโมเดลสุดท้ายแล้ววัดผลบน Test Set
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - แยก Test Set ไว้ต่างหากอย่างถูกต้อง (3 คะแนน)
    - ใช้ Cross-Validation และวาดกราฟเปรียบเทียบ Train vs CV ได้ (4 คะแนน)
    - ชี้จุด Overfitting และเลือกโมเดลที่เหมาะสมที่สุดได้ถูกต้อง (3 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** กราฟ 2 เส้นแสดงให้เห็นชัดว่าที่ `max_depth=12` Train=1.00 แต่ CV=0.84 ส่วน `max_depth=4` ให้ CV สูงสุดที่ 0.93 จึงเลือก `depth=4`
