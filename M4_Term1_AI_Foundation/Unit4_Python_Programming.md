  | 5–15 นาที | บรรยาย/สาธิต | สาธิต `input()`, `int()`, `float()` และเครื่องหมาย `+ - * /` |

  - **โจทย์/สถานการณ์:** สร้างโปรแกรมโต้ตอบกับผู้ใช้ที่รับข้อมูลจริงแล้วคำนวณผลลัพธ์ที่มีประโยชน์ทันที

### คาบที่ 19: ตัวดำเนินการ (Operators) และการจัดรูปแบบ `f-string`
- **จุดประสงค์การเรียนรู้:**
  1. ใช้ตัวดำเนินการทางคณิตศาสตร์ (`//`, `%`, `**`) และตัวดำเนินการกำหนดค่าได้
  2. จัดรูปแบบข้อความและทศนิยมด้วย `f-string` ให้สวยงามและอ่านง่ายได้
- **แนวคิดหลัก:** `f-string` ช่วยให้แทรกตัวแปรและกำหนดจำนวนทศนิยม (เช่น `:.2f`) ลงในข้อความได้สะดวกกว่าการเชื่อมข้อความแบบเดิม
- **ตารางเวลา:**
  | ช่วงเวลา | กิจกรรม | วิธีสอน |
  |---|---|---|
  | 0–5 นาที | เปิดคาบ/ทบทวน | ทบทวนผลลัพธ์ทศนิยมยาว ๆ ที่ได้จากคาบที่แล้ว |
  | 5–15 นาที | บรรยาย/สาธิต | สอน `//`, `%`, `**` และ `f"{value:.2f}"` |
  | 15–25 นาที | ฝึกปฏิบัติแบบมีผู้ช่วย | ทดลองใช้ `//` และ `%` แปลงจำนวนนาทีเป็น "ชั่วโมง และ นาที" |
  | **25–50 นาที (50%)** | **โครงงานปลายคาบ** | ลงมือทำเอง |
- **โครงงานปลายคาบ:**
  - **ชื่อโครงงาน:** ระบบออกใบเสร็จร้านค้าดิจิทัล
  - **โจทย์/สถานการณ์:** ร้านค้าต้องการโปรแกรมคิดเงินที่พิมพ์ใบเสร็จออกมาให้ลูกค้าอ่านง่าย มีทศนิยม 2 ตำแหน่งตรงตามหลักบัญชี
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** โปรแกรม Python ที่รับชื่อสินค้า ราคา และจำนวน แล้วพิมพ์ใบเสร็จจัดชิดแนวสวยงามด้วย `f-string` พร้อมแสดงราคารวม, VAT 7% และยอดสุทธิ (ทศนิยม 2 ตำแหน่ง)
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. รับข้อมูลสินค้า 2 รายการ (ชื่อ, ราคา, จำนวน)
    2. คำนวณราคารวม, ภาษี 7%, และยอดสุทธิ
    3. ใช้ `f-string` จัดรูปแบบแสดงใบเสร็จและจำกัดทศนิยม `:.2f`
    4. ทดสอบรันด้วยตัวเลขทศนิยมจริง
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - คำนวณราคารวมและ VAT ถูกต้อง (3 คะแนน)
    - ใช้ `f-string` และกำหนดทศนิยม 2 ตำแหน่งได้ถูกต้อง (4 คะแนน)
    - รูปแบบใบเสร็จเรียบร้อยอ่านง่าย (3 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** ใบเสร็จแสดง `Subtotal: 250.00 THB`, `VAT (7%): 17.50 THB`, `Total: 267.50 THB`
  - **ตัวเลือกเสริม (Extension):** ใช้ `//` และ `%` คำนวณแต้มสะสม (ทุก 50 บาท ได้ 1 แต้ม) พร้อมแจ้งยอดขาดอีกกี่บาทถึงจะได้แต้มเพิ่ม
  - **แนวทางช่วยเหลือ (Scaffold):** เตรียมตัวอย่าง `print(f"รวม: {total:.2f} บาท")` ให้ดูเป็นแบบ
- **วัสดุ/เครื่องมือที่ต้องเตรียม:** คอมพิวเตอร์, JupyterHub บน AI Server
- **คำถามสะท้อนคิดปิดคาบ:**
  1. เครื่องหมาย `/` กับ `//` ต่างกันอย่างไร และควรใช้เมื่อใด?
  2. `f-string` ช่วยให้โค้ดอ่านง่ายขึ้นกว่าการใช้เครื่องหมาย `+` เชื่อมข้อความอย่างไร?

  | ช่วงเวลา | กิจกรรม | วิธีสอน |

### คาบที่ 23: ลูป `for` และฟังก์ชัน `range()`

  | ช่วงเวลา | กิจกรรม | วิธีสอน |

  | 5–15 นาที | บรรยาย/สาธิต | อธิบาย `for i in range(...)` รูปแบบ 1, 2, และ 3 พารามิเตอร์ |
  | 15–25 นาที | ฝึกปฏิบัติแบบมีผู้ช่วย | ทดลองนับถอยหลังและพิมพ์เลขคู่ 2–20 |

  - **ชื่อโครงงาน:** เครื่องสร้างตารางสูตรคูณและตารางดอกเบี้ย/การออม
  - **โจทย์/สถานการณ์:** สร้างเครื่องมือช่วยเรียนคณิตศาสตร์ที่ผู้ใช้ระบุแม่สูตรคูณและจำนวนแถวที่ต้องการได้เอง
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** โปรแกรม Python ที่ใช้ `for` + `range()` สร้างตารางสูตรคูณตามแม่ที่ผู้ใช้เลือก (พร้อมเลือกตัวเลือกเสริมสร้างตารางออมเงินรายเดือน)

  - **แนวทางช่วยเหลือ (Scaffold):** ย้ำกฎ `range(1, n+1)` เพื่อให้ได้เลข `1` ถึง `n`

  - **โจทย์/สถานการณ์:** ทดสอบสมรรถนะการเขียนโปรแกรมแก้ปัญหาจริง 2 ข้อภายในเวลาจำกัด (เช่น ข้อ 1: โปรแกรมรับข้อมูลในลูป+เงื่อนไข, ข้อ 2: ฟังก์ชันประมวลผล List/Dict หรือวิเคราะห์ CSV)
  - **ชิ้นงานที่ต้องส่ง (Deliverable):** Jupyter Notebook (บน JupyterHub) ที่มีโค้ดแก้โจทย์ครบ 2 ข้อ รันผ่านสมบูรณ์และแสดงผลลัพธ์ตรงตาม Test Cases ที่กำหนด
  - **ขั้นตอนทำงานแบบทีละขั้น:**
    1. อ่านโจทย์ทั้ง 2 ข้อและวางแผน Input-Process-Output
    2. เขียนโค้ดทีละส่วนและทดสอบรันทุกครั้งที่เพิ่มฟีเจอร์
    3. ตรวจสอบผลลัพธ์กับ Test Cases ตัวอย่าง 2–3 ชุด
    4. ส่งไฟล์ Jupyter Notebook (.ipynb) ก่อนหมดเวลา
  - **เกณฑ์ประเมิน (Rubric ย่อ 10 คะแนน):**
    - ข้อที่ 1 ทำงานถูกต้องตามเงื่อนไข (5 คะแนน)
    - ข้อที่ 2 ใช้โครงสร้างข้อมูล/ฟังก์ชันทำงานถูกต้อง (5 คะแนน)
  - **ตัวอย่างผลงานที่ถือว่าผ่าน:** โค้ดรันผ่านทั้ง 2 ข้อโดยไม่ Error และคำนวณตรงตาม Test Case ตัวอย่าง
  - **ตัวเลือกเสริม (Extension):** โจทย์โบนัสข้อที่ 3 (การอ่านไฟล์ CSV แล้ววาดกราฟสรุป 1 รูป)
  - **แนวทางช่วยเหลือ (Scaffold):** อนุญาตให้เปิดดู Cheat Sheet คำสั่งของตนเองที่จดไว้ได้ (Open-notes) เพื่อฝึกการค้นคว้าจริง
