# ม.4 ภาคเรียนที่ 1: AI Foundation (40 คาบ)

**คำอธิบายรายวิชา:** พื้นฐานการคิด การเขียนโปรแกรม และการใช้ AI  
**เครื่องมือ/อุปกรณ์:** Notebook/Tablet นักเรียน, AI Server (Ollama 7B–14B + Open WebUI, JupyterHub), NAS Storage (Synology DS223j), โปรแกรมตารางคำนวณ/เอกสาร (LibreOffice `[เสริม]`), ไฟล์ CSV

---

## ตารางสรุปภาพรวม 40 คาบ

| คาบที่ | ชื่อคาบ | แนวคิดหลัก | โครงงานปลายคาบ |
|---|---|---|---|
| 1 | รู้จัก AI/LLM และข้อจำกัดการตอบผิด | Generative AI, LLM และอาการหลอนข้อมูล (Hallucination) | ตารางเปรียบเทียบคำตอบ AI 3 ตัวพร้อมจุดจับผิด |
| 2 | สูตรเขียน Prompt 5 องค์ประกอบ | บทบาท บริบท งาน รูปแบบผลลัพธ์ ข้อจำกัด | ชุด Prompt 3 เวอร์ชันที่ปรับปรุงจนใช้งานได้จริง |
| 3 | เทคนิค Prompt ขั้นสูง (Few-shot & CoT) | การให้ตัวอย่าง แบ่งขั้นตอน และให้ AI ตรวจงานตัวเอง | ชุดทดสอบเปรียบเทียบ Prompt ก่อน-หลังใช้เทคนิค |
| 4 | ใช้ AI ช่วยเรียนและเขียนโค้ดอย่างมีวิจารณญาณ | การตรวจสอบคำตอบและแหล่งอ้างอิง | รายงานภารกิจจับผิดคำตอบ AI 3 กรณี |
| 5 | คลัง Prompt ส่วนตัวเพื่อการเรียนรู้ | การจัดหมวดหมู่และบันทึก Prompt ที่ใช้ซ้ำได้ | คลัง Prompt Library 5 รายการที่ทดสอบแล้ว |
| 6 | อคติและความเป็นส่วนตัวในยุค AI | อคติของข้อมูล (Bias) และข้อมูลส่วนบุคคล (PII) | การ์ดวิเคราะห์อคติและความเสี่ยงข้อมูล 2 กรณีศึกษา |
| 7 | ลิขสิทธิ์ ความซื่อสัตย์ และ Deepfake | ขอบเขตการใช้ AI อย่างซื่อสัตย์และการสังเกตสื่อปลอม | คู่มือแยกแยะ Deepfake และเกณฑ์ใช้ AI อย่างซื่อสัตย์ |
| 8 | ร่างกติกาการใช้ AI ของห้องเรียน | ข้อตกลงร่วมด้านจริยธรรมและความรับผิดชอบ | เอกสาร AI Use Policy ประจำห้องเรียน |
| 9 | รู้จักข้อมูลและชนิดข้อมูลรอบตัว | ข้อมูล 4 ชนิด (ตัวเลข หมวดหมู่ ข้อความ ภาพ) และแหล่งข้อมูล | แผนผังจำแนกข้อมูลจากแอปหรือชีวิตประจำวัน |
| 10 | ทำความสะอาดข้อมูล: ค่าว่างและข้อมูลซ้ำ | การตรวจจับและจัดการ Missing Values / Duplicates | สเปรดชีตข้อมูลนักเรียนที่กำจัดค่าว่างและซ้ำแล้ว |
| 11 | ทำความสะอาดข้อมูล: รูปแบบและมาตรฐาน | การจัดรูปแบบวันที่ ตัวเลข และหมวดหมู่ให้สม่ำเสมอ | ชุดข้อมูล Clean Dataset พร้อมบันทึก Log การแก้ไข |
| 12 | สถิติพื้นฐาน: ค่ากลางของข้อมูล | ค่าเฉลี่ย (Mean), มัธยฐาน (Median), ฐานนิยม (Mode) | แดชบอร์ดสูตรคำนวณค่ากลางใน LibreOffice Calc / CSV บน NAS [เสริม] |
| 13 | สถิติพื้นฐาน: ค่าผิดปกติและการกระจาย | การหาค่าผิดปกติ (Outlier) และผลกระทบต่อค่าเฉลี่ย | รายงานวิเคราะห์ค่าผิดปกติจากชุดข้อมูลจริง |
| 14 | เลือกกราฟให้ตรงกับข้อมูลและจับผิดกราฟ | ชนิดกราฟ (แท่ง เส้น พาย กระจาย) และกราฟที่ชวนเข้าใจผิด | ชุดกราฟเปรียบเทียบแบบถูกหลัก vs แบบชวนเข้าใจผิด |
| 15 | เล่าเรื่องด้วยข้อมูล (Data Storytelling) | การเรียงลำดับข้อมูล ภาพ และข้อสรุปเพื่อสื่อสาร | สไลด์/แผ่นภาพสรุป 3 กราฟพร้อมข้อค้นพบ |
| 16 | เก็บข้อมูลจริงในห้องและส่งออกเป็น CSV | การออกแบบแบบสอบถามสั้นและการจัดโครงสร้าง CSV | ไฟล์ CSV ชุดข้อมูลจริงของห้องเรียนพร้อมใช้งานใน Python |
| 17 | เริ่มต้น Python บน JupyterHub บน AI Server | การตั้งค่า JupyterHub, `print()`, ตัวแปร และชนิดข้อมูล | โปรแกรมบัตรแนะนำตัวดิจิทัลด้วย Python |
| 18 | การรับค่าและคำนวณพื้นฐานใน Python | `input()`, การแปลงชนิดข้อมูล และการคำนวณเบื้องต้น | โปรแกรมทักทายและคำนวณอายุ/ส่วนสูงอัตโนมัติ |
| 19 | ตัวดำเนินการและจัดรูปแบบข้อความ f-string | ตัวดำเนินการคณิตศาสตร์ และ `f-string` | ใบเสร็จรับเงินดิจิทัลจากโปรแกรม Python |
| 20 | เครื่องคิดเลขค่าใช้จ่ายรายวัน | การประยุกต์ `input()`, ตัวดำเนินการ และการแปลงชนิดข้อมูล | โปรแกรมเครื่องคิดเลขสรุปค่าใช้จ่ายและเงินทอน |
| 21 | เงื่อนไขพื้นฐาน `if / else` | การตัดสินใจสองทางและตัวดำเนินการเปรียบเทียบ | โปรแกรมตรวจสอบสิทธิ์ส่วนลดร้านค้า |
| 22 | เงื่อนไขหลายทาง `if / elif / else` | การจัดลำดับเงื่อนไขและตรรกะ `and / or` | โปรแกรมตัดเกรดและประเมินผลอัตโนมัติ |
| 23 | ลูป `for` และ `range()` | การทำซ้ำแบบรู้จำนวนรอบ | โปรแกรมสร้างตารางสูตรคูณแม่ที่ผู้ใช้เลือก |
| 24 | ลูป `while` และการควบคุมรอบ | การทำซ้ำแบบมีเงื่อนไขหยุด (`break`) | โปรแกรมเกมทายตัวเลขพร้อมนับจำนวนครั้ง |
| 25 | ประยุกต์ลูปซ้อนและตัวนับ | การใช้ตัวแปรสะสมค่า (Accumulator) ในลูป | โปรแกรมจำลองระบบคิดเงินร้านค้าหลายรายการ |
| 26 | โครงสร้างข้อมูล List และการเข้าถึง | การสร้าง ลบ เพิ่ม และอ้างอิง Index ใน List | โปรแกรมจัดการรายการสิ่งที่ต้องทำ (To-Do List) |
| 27 | การวนลูปประมวลผลข้อมูลใน List | `for item in list` และการหาผลรวม/ค่าสูงสุด | โปรแกรมวิเคราะห์คะแนนสอบของนักเรียน |
| 28 | ประยุกต์ List กับสถิติเบื้องต้น | ค่าเฉลี่ย สูงสุด ต่ำสุด และการคัดกรองข้อมูลใน List | โปรแกรมสรุปผลคะแนนและคัดผู้ผ่านเกณฑ์ |
| 29 | โครงสร้างข้อมูล Dictionary (Key-Value) | การเก็บข้อมูลแบบจับคู่ชื่อ-ค่า | โปรแกรมสมุดรายชื่อและเบอร์ติดต่อ |
| 30 | ประยุกต์ Dictionary จัดการคลังสินค้า | การอัปเดตค่า ค้นหา และคำนวณจาก Dictionary | โปรแกรมเช็กราคาและคำนวณยอดขายสินค้า |
| 31 | สร้างฟังก์ชันด้วย `def` และ `parameter` | การแยกส่วนโค้ดเป็นฟังก์ชันย่อย | โปรแกรมเครื่องมือคำนวณแบบแยกฟังก์ชัน |
| 32 | การส่งค่ากลับ `return` และรีแฟกเตอร์โค้ด | การใช้ `return` เพื่อนำผลไปคำนวณต่อ | โปรแกรมเดิมที่ปรับโครงสร้างเป็นฟังก์ชันสะอาดตา |
| 33 | อ่านไฟล์ CSV ด้วย `pandas` เบื้องต้น | `pd.read_csv()`, `.head()`, `.describe()` | สคริปต์วิเคราะห์ชุดข้อมูล CSV ของห้องเรียน |
| 34 | วาดกราฟข้อมูลด้วย `matplotlib` | กราฟแท่ง/เส้น/กระจาย จาก DataFrame | รายงานภาพกราฟวิเคราะห์ข้อมูลห้องเรียนจาก Python |
| 35 | ทักษะดีบักและการใช้ AI อธิบาย Error | การอ่าน Traceback และใช้ AI อย่างมีวิจารณญาณ | สคริปต์ Python ที่แก้บั๊กครบ 5 จุดพร้อมบันทึกการแก้ |
| 36 | ทบทวนและทดสอบปฏิบัติเขียนโค้ด | การรวมแนวคิดตัวแปร เงื่อนไข ลูป ลิสต์ ฟังก์ชัน | ชุดโปรแกรมแก้โจทย์ปฏิบัติขนาดสั้นที่รันผ่าน 100% |
| 37 | วางแผน Mini Project และเขียน Flowchart | การตั้งโจทย์ ขอบเขต เกณฑ์สำเร็จ และ Flowchart | ใบวางแผนโครงงาน + Flowchart ระบบ |
| 38 | พัฒนา Mini Project (ส่วนรับข้อมูลและตรรกะ) | การเขียนโค้ดแกนหลักตาม Flowchart | โมดูลรับข้อมูลและประมวลผลที่รันได้จริง |
| 39 | พัฒนา Mini Project (วิเคราะห์/แสดงผลและทดสอบ) | การเชื่อมต่อข้อมูล ทดสอบ Edge Case และปรับปรุง | โปรแกรม Python ฉบับสมบูรณ์พร้อมทดสอบ |
| 40 | นำเสนอ Mini Project และสะท้อนผล | การสื่อสารผลงานทางเทคนิคและการประเมินตามรูบริก | การสาธิตโปรแกรม 3 นาที + แบบประเมินตนเอง |

## โครงงานรวบยอดประจำภาคเรียน
**โปรแกรม Python วิเคราะห์ข้อมูลหรือคำนวณใช้งานจริง** โดยต่อยอดจากทักษะทั้ง 4 หน่วย:
- ใช้ **Prompt Engineering (คาบ 1–5)** และ **AI Ethics (คาบ 6–8)** เป็นแนวทางในการใช้ AI ช่วยเขียนและดีบักโค้ดอย่างซื่อสัตย์
- ใช้ **ชุดข้อมูล CSV ของห้อง (คาบ 9–16)** เป็นข้อมูลนำเข้าจริง
- ใช้ **Python + pandas + matplotlib (คาบ 17–36)** ในการประมวลผลและสร้างกราฟสรุปผลใน **Mini Project (คาบ 37–40)**
